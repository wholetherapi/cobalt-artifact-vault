# Nimbus: Sparse Attention for Edge Vision

## Availability

This package is not public yet. It will hold the released artifacts for the paper once the lab's internal artifact review is complete. The directories currently present are placeholders and do not contain the implementation.

## Paper Information

- **Authors**: Elena Sokolova, Ravi Menon, Sofia Marchetti
- **Venue**: Vision Systems Conference 2026
- **Artifact type**: code, experiment configuration, evaluation scripts

## Abstract

Nimbus explores block-sparse attention schedules tailored to edge vision backbones, targeting a 2.3x reduction in on-device latency without measurable accuracy loss.
