# Research and Freelance Vault

This repository is my working vault while I finish my graduate programme and
take on short freelance product engagements.

- `School/` - thesis materials, course schedules, graduation paperwork and
  coursework project submissions.
- `Work/Projects/` - paid client work and product deliverables.
- `tools/` - small utilities used for the staging and reporting exercises.
- `inbox/` - unsorted items that still need filing.
- `TRACKING.md` - open items with their source-marker references.
- `CONVENTIONS.md` - filing and tracking conventions.
