# Vocabulary Distillation for Multilingual Speech Models

## Availability

This package is public and contains the released artifacts for the paper. The implementation, experiment configuration and evaluation scripts are available below.

## Paper Information

- **Authors**: Mateo Ferreira, Amara Diallo, Noah Feldman
- **Venue**: Speech & Language Technology Conference 2026
- **Artifact type**: code, experiment configuration, evaluation scripts

## Abstract

We distill a shared subword vocabulary from eleven speech corpora, recovering 94 percent of the monolingual word error rate while shrinking the decoder embedding table by more than half.
