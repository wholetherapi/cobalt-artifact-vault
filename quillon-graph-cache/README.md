# Quillon: Graph-Aware KV Cache Reuse

## Availability

This package is public and contains the released artifacts for the paper. The implementation, experiment configuration and evaluation scripts are available below.

## Paper Information

- **Authors**: Hana Ito, Priya Raman, Viktor Petrov
- **Venue**: Machine Learning Conference 2026
- **Artifact type**: code, experiment configuration, evaluation scripts

## Abstract

Quillon constructs a dependency graph over cached key-value blocks so that repeated prompts reuse partial attention state, improving serving throughput by 1.8x on production-shaped traces.
