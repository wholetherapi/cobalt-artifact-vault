# Avalon: Streaming Inference for Long-Context Transformers

## Availability

This package is public and contains the released artifacts for the paper. The implementation, experiment configuration and evaluation scripts are available below.

## Paper Information

- **Authors**: Priya Raman, Tomasz Zielinski, Hana Ito
- **Venue**: Efficient Learning Systems Conference 2026
- **Artifact type**: code, experiment configuration, evaluation scripts

## Abstract

We introduce a chunked streaming attention scheduler that keeps long-context decoding latency flat across context windows up to 128k tokens while cutting peak memory by 41 percent relative to dense recomputation baselines.
